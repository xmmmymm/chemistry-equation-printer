# 归一映射表（B8 的实现依据）

> 老师说的口语 → 引擎能懂的枚举值。**实现位置**：`tools/preflight.js`（`BOOK_ALIASES` /
> `DIFFICULTY_ALIASES` / `VERSION_TYPE_ALIASES` / `VERSION_STRATEGY_ALIASES` / `SCENARIO_ALIASES`
> + `matchKey()` 文本归一）。
>
> 归一顺序：**① 别名直命中 → ② 精确键匹配 → ③ 唯一子串匹配 → ④ 多命中 = 歧义（走 B6 列候选）
> → ⑤ 零命中 = 拒绝（走 B6，附枚举表）**。**永不自动放宽到全库。**

---

## 一、文本层归一（`matchKey()`）

| 规则 | 例子 |
|---|---|
| 全角 → 半角（ASCII 区） | `必修１` → `必修1`；`Ａ` → `A` |
| 全角空格 → 普通空格 → 再删所有空白 | `必修 第一册` → `必修第一册` |
| 中文数字 → 阿拉伯数字 | `第一章` → `第1章`；`必修一` → `必修1`；`选必三` → `选必3` |
| 删连接标点 | `物质及其变化——` → `物质及其变化`；`1,4-丁二醇` 的 `,`/`-` 去掉 |
| 小写化 | `PREFER CHEMICAL` → `preferchemical` |

## 三、章 / 节

章名与节名以**题库中真实出现的记录**为准（数据驱动，含树外的九年级），并用
`data/classifications.json` 的章节树补全。

| 口语 | 归一结果 | 说明 |
|---|---|---|
| 第一章 | `第一章 物质及其变化` | 章名跨册唯一，直接唯一子串命中 |
| 离子反应 | `必修第一册 / 第一章 物质及其变化 / 第二节 离子反应` | 节名简称，唯一命中；映射结果里带上它的册/章 |
| 复习与提高 | **歧义（6 个候选）** | 这个名字本身唯一，但出现在 6 个不同的 册/章 组合里 → **列候选让老师选** |

**歧义判定按「记录组合」**（book + chapter + section），不按单个名称——因为引擎语义是
「节 = 跨册跨章匹配该节名」，实际范围并不等价。

**已勾册别时**：只在勾中的册里找，找不到就是零命中（**不**回退到全库）。

## 九、明确拒绝的非枚举值（B8）

| 老师说的 | 处理 |
|---|---|
| `starred` / 星标 / 收藏 | **拒绝**：题库 `starred` 全 false → 改用 `tags` 标签筛选 |
| `mustInclude` / 必出题机制 | **拒绝**：题库 `mustInclude` 全 false → 改用 `manualEntryIds` 手选必出 |
| 开放题 / 探究题 / 论述题（题型 H） | **拒绝**：题库 `openPrompt` 全空 → 改用 C 题型 |
| 任意不在枚举内的值 | **拒绝 + 附枚举表**，不猜 |
