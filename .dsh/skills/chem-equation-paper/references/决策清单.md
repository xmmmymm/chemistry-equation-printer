# 决策清单 · 必问 / 可默认 / 永不问

> 来源：需求规格 v1.1 §3.1 决策块 11（`interaction.mustAsk` / `restateModifiable` / `neverAsk`）
> 用法：intake 轮**只问必问项**；可默认项**先按默认值填，放进复述框让老师改**；永不问项**一个都不要问**。

---

## 一、必问（3 项，缺一不可，**不得静默替老师决定**）

| # | 项目 | 键 | 选项 / 形式 | 老师答「随便/你定」时 |
|---|---|---|---|---|
| 1 | **场景** | `scenario` | `homework` 课后作业（默认）｜`timedDrill` 课堂限时练｜`examPrep` 备考练习 | 取 `homework` |
| 2 | **范围** | `generation.scopes` | 口语即可：「全库」「必修一第一章」「选必 3 的烃」「九上和九下」「全库但别出有机」 | 取全库（`{}`） |
| 3 | **版本策略** | `generation.versionStrategy` | 见 §4.1 六选一 | **建议 `preferChemical`**；答「推荐/照旧」→ `preferChemical` |

> ⚠ **漏问会被硬拦**：`versionStrategy` 缺失或写成 `"ASK"` 时，`tools/preflight.js` 直接给
> `ASK_VERSION_STRATEGY`（`exitCode: 2`，`tools/run-paper.js` 也不进导出），
> `restate.versionStrategy` 同样如实回显 `"ASK"`。**不会**静默用 `chemicalOnly` 出卷。
> 看到这个 code = 回 intake 补问第 3 问。话术见 `文案模板.md` §四。

### 为什么版本策略必须问

同一道「铁与硫酸铜溶液的反应」有化学 / 离子两种写法。策略一变，**可出题数会变**：

| 范围 | `chemicalOnly` | `allAvailable` | 差 |
|---|---|---|---|
| 全库 | 301 | 392 | −91 条 |
| 选择性必修3（有机） | 78 | 78（其中 17 条有离子版本） | 0（条目数相同；但 `ionicOnly` = **17**） |
| 选择性必修2 | 3 | 6 | −3 条 |

老师不说清楚，出了 10 题「化学方程式作业」却混进离子方程式，是**返工级**错误。

## 二、可默认项（**先填默认值**，在复述框里让老师改；不要单独问一轮）

| 项目 | 键 | 默认值 | 复述框里怎么呈现 |
|---|---|---|---|
| 题量 | `generation.totalCount` | **10** | 「共 10 题」 |
| 题型分布 | `generation.questionTypeCounts` | `{B:0,C:0,D:0,E:0,H:0}`（全 0 = 引擎自动补足） | 「题型：自动（B/D/E 必出，C 视素材）」 |
| 难度目标 | `generation.difficultyCounts` / `difficultyRatios` | 全 0 = **不限制**（软约束） | 「难度：不限制（按题库实际分布）」 |
| 手选必出 | `generation.manualEntryIds` | `[]` | 「手选必出：无」 |
| 排除范围 | `generation.exclude` | `{}` | 「排除：无」 |
| 导出通道 | `export.pdf` / `export.docx` | 均 `true`（PDF 双卷 + Word 双卷） | 「导出：PDF 题目卷+答案卷、Word 题目卷+答案卷」 |
| 图片 | `export.images` | `false`（**点名才产**） | 「图片：不出（需要请说）」 |
| 输出目录 | `outputDir` | `null` → `out/{yyyy-mm-dd}/` | 显示实际绝对路径 |
| 附加要求 | `extraAcceptance` | `[]` | 「附加要求：无」 |

> 附加要求（第 4 问）虽然形式上是「问」，但**老师可以留空**，所以不计入必问项。

## 三、永不问（`neverAsk`，问了就是错的）

| # | 项目 | 为什么永不问 |
|---|---|---|
| 1 | **卷面参数**（`layoutSettings`：纸型/页边距/栏数/字体/字号/行距/题距/答案线/每页固定题数） | skill **内嵌固定模板** `layout.yml`；老师的要求是「卷面格式固定」，问了反而暴露无关决策 |
| 2 | `allowDuplicateEntry` | 恒定 `false`（同条目一卷一次） |
| 3 | `includeMustInclude` | 恒定 `false`（题库 `mustInclude` 全 false，机制不参与） |
| 4 | **学习项目挂靠**（`projectScope` / `projectCounts` / `round` / `allowOverRound`） | 本 skill 不与应用联动；`opts` 全不传 |
| 5 | **H 开放题数量** | `H` 恒 0（题库 `openPrompt` 全空）；老师主动要 → B7 拒绝 |
| 6 | **starred 星标筛选** | 题库 `starred` 全 false；老师想要 → 改用 `tags` 筛选（B7） |
| 7 | 是否写回题库出题次数 / 是否记入历史作业 | v1.1 已取消，永不写 |
| 8 | 题库数据锁是否需要处理（`data:lock`） | 题库是**本项目自有数据**；数据锁异常**不阻塞**出卷（B12），只在报告里标注，不拿这个去问老师 |
| 9 | 是否允许同条目不同版本 | 只在 **B1 四选项流的第 ④ 项**里、题量不足时**临时**问一次 |

## 四、冲突链（当次 > 记忆 > 默认）

老师这次说的 > `.dsh/skill-state/last-run.json` 记的偏好 > 系统默认。

| 场景 | 取值 |
|---|---|
| 老师说「跟上次一样」 | 从记忆取 `scenario` / `scopes` / `versionStrategy` / `totalCount` / `questionTypeCounts` / `difficulty`，**只复述变化项**（AC-12） |
| 老师说「跟上次一样但 15 题」 | 记忆供范围/策略，题量取当次的 15；预检数**重新算** |
| 老师说「上次那个范围，但这次用离子」 | 范围取记忆，策略取当次 |
| 老师说「这次全库」（明确主张默认值） | job 里写 `"useMemory": false`，否则记忆会把空 `scopes` 补掉 |
| 记忆文件损坏 / 缺失 | **系统默认 + 一行说明**（「上次的偏好记录读不出来，这次按默认来」），**不阻塞** |
| 老师这次明确说了与记忆相反的值 | 以当次为准，**并更新记忆** |

### ⚠ 空值 ≠ 没填（必须记住）

规格 §3.3 的默认值本身就是「空」的形态：

| 字段 | 默认（空） | 含义 |
|---|---|---|
| `generation.scopes` | `{}` | 全库 |
| `generation.questionTypeCounts` | 全 0 | 引擎自动补足 |
| `generation.difficultyCounts` | 全 0 | 不限制难度 |

所以「空」既可能是**默认值**，也可能是**没填**——两者无法区分。规矩：

- 记忆**只补「字段不存在」的项**；字段存在但为空 → 仍会被记忆补（因为无法判断是默认还是没填）。
- 要**明确主张默认值** → 在 job 里写 `"useMemory": false`（或预检加 `--no-memory`）。
- 老师说「全库」「难度不限」这类明确指令时，**一定要带上 `useMemory: false`**，否则会被上次记忆覆盖。

## 五、intake 轮的两个后台动作（老师看不见）

```powershell
node tools/skill-state.js pending   # 有未完成项 → 复述框/开场提示「上次有导出失败的文件，要现在重试吗？」
node tools/skill-state.js drift     # 题库数据锁异常 → 抄进 job.snapshot，报告里标注
```

`pending` 与 `drift` **都不阻塞出卷**，只是提示与标注。
（`node tools/skill-state.js state` 一次拿全三块：drift + memory + pending。）

## 六、intake 覆盖度（AC-18）：必问项到底是谁给的

`preflight` 结果里的 `intakeCoverage` 把每项参数的**来源**标出来，供复述框与确认闸门使用：

| 来源 | 含义 | 复述框里怎么讲 |
|---|---|---|
| `explicit` | **当次 job 显式给出** = agent 从老师那儿问到的 | 正常复述 |
| `memory` | 当次没给，由 `.dsh/skill-state/last-run.json` 补上 | **必须点明「这是沿用上次」** |
| `default` | 当次没给、记忆也没有 → 系统默认 | 说明「按默认定的」 |

`verdict` 三档：`intake-complete`（必问 3 项都 explicit）/ `intake-incomplete`
（有必问项被记忆或默认替答 → `unasked[]` 列出）/ `blocked`（版本策略仍是 ASK）。

> ⚠ **为什么需要它**：`restate.versionStrategyAsked` 只表示「最终值不是 ASK」——**记忆补上的
> 同样为 `true`**，不能当「问过老师」的证据。实测：`{"jobVersion":1,"generation":{"totalCount":10}}`
> 这种什么都没说的 job，会被记忆补成「跟上次一样」并 `exit 0` 放行。
> `intakeCoverage` 让这种**漏问当场可见**。

**确认闸门**：`node tools/run-paper.js <job.json>` 不带 `--confirmed` → 只回
`CONFIRM_REQUIRED` + `restate` + `intakeCoverage`，**零卷子产出**（`exitCode 2`）；
老师确认后带 `--confirmed` 才进导出。（`dryRun` 与 `--render-check` 不产交付物，豁免。）
