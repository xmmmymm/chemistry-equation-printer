**几条值得说明的判断**：

- **第 1 条**不是「新知识」，而是**对称性缺口**：`R0185 铅酸蓄电池的放电` 早就有离子式
  `Pb + PbO₂ + 4H⁺ + 2SO₄²⁻ ⇌ 2PbSO₄ + 2H₂O`，而它的逆过程（充电）却没有。
- **第 2/3 条**的「水 / 醇」条件**必须跟着离子式一起走**：这两个反应的区别正是溶剂，
  离子式若丢掉条件就变成同一个式子，考点就没了。所以条件从化学式版原样复制。
- **第 5–7 条**（苯酚 / 苯酚钠）是「弱酸不拆、强电解质拆」的标准形态：
  苯酚 `C₆H₅OH` 保持分子式，`NaOH`/`HCl`/`NaHCO₃` 一侧拆成离子。
- **第 8/15 条**（银镜）的离子式里配合物带系数，数据里写成 `2 [Ag(NH₃)₂]⁺`
  （**系数与方括号之间留一个空格**）——引擎的行解析器 `^(\d+)(?=[A-Za-z])` 只认「数字后紧跟字母」的系数，
  不认 `2[Ag(NH₃)₂]⁺`；留空格后 `^(\d+)\s+` 分支能正确取到系数，且 `editorLine()` 回填也是这个形态。
- **第 16 条**产物写作 `NH₃CH₂COOH⁺`，与库内既有写法一致
  （参见 `R0366` 苯胺：`C₆H₅NH₂ + H⁺ = C₆H₅NH₃⁺`，同样是「加质子」型）。

## 三、明确不补的 183 条——分类与理由

| 类别 | 为什么不补 | 代表条目 |
|---|---|---|
| 燃烧 / 高温固气反应 | 气相或固相，无自由离子 | R0001 磷在氧气中燃烧、R0016 甲烷的燃烧、R0022 碳还原氧化铁、R0095 铝热反应 |
| 受热分解 | 非溶液体系，且多为固相分解 | R0005 氧化汞受热分解、R0027 碳酸钙高温分解、R0110 碳酸氢钠受热分解 |
| 氧化物 / 非金属氧化物与水化合 | 氧化物是固体（或气体），与水化合不产生自由离子，标准答案就是分子式 | R0024 CO₂ + H₂O、R0028 CaO + H₂O、R0157 SO₃ + H₂O |
| 熔融电解 | 熔融盐虽电离，但中学口径写分子式 | R0054 电解冶炼铝、R0201 电解冶炼镁、R0300 电解熔融氯化钙 |
| 非水体系电池 / 熔融电池 | 非水溶剂，无自由水合离子 | R0307 锂-亚硫酰氯电池、R0295 普通锌锰电池 |
| 浓酸 / 石灰乳 / 晶体研磨语境 | 反应物是浓酸或悬浊液，写离子式不当 | R0159 铜与浓硫酸、R0175 铜与浓硝酸、R0117 漂白粉的制备（石灰乳）、R0183 Ba(OH)₂·8H₂O 与 NH₄Cl 晶体 |
| 纯有机反应 | 无强电解质参与，离子式与分子式同形 | 全部加聚 / 缩聚（R0376–R0393）、取代 / 加成（R0187–R0192、R0320、R0332–R0336）、酯化（R0198、R0361）、裂化裂解（R0206–R0209） |
| 气体化合 / 气体歧化 | 气相 | R0033 H₂ + Cl₂、R0169 NH₃ + HCl、R0167 NO₂ + H₂O、R0166 NO 的氧化 |

> 判据的核心是：**离子方程式不是「把化学方程式改写成离子形式」的形式练习，而是描述水溶液中真实存在的离子行为**。
> 没有自由离子的反应，硬写出来只会得到与分子式一字不差的「假离子式」。

### 第二轮拍板的统一规则（供后续同类判断）

1. **有自由水合离子才补**：强酸/强碱/可溶盐在**水溶液**里拆；非水体系（无水乙醇、浓硫酸介质、糊状电池、非水电解质）不补。
2. **固-液界面反应不补**：氧化物/过氧化物与水、不溶固体（CaC₂）作反应物。
3. **有机分子间取代不补**：苯酚+Br₂、醇+HBr 这类反应物是分子、无离子源的。
4. **碱性体系里两性金属的产物写配离子**：Zn → `Zn(OH)₄²⁻`（与库内 `R0308 锌-空气电池`、`R0137/R0138` 的 `Al(OH)₄⁻` 口径一致），不再写 `Zn(OH)₂` / `ZnO`。
5. **总反应含离子的条目同时给 `ionic` 版本**：电池总反应若写成含 OH⁻ 的形式，`ionic` 版本给同一式子（便于按版本策略筛选）。
