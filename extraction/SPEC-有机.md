## 二、一行式书写规范增补（有机表示法）

1. **双键写 `=`，三键写 `≡`**（直接用这两个字符）：
   乙烯 `CH2=CH2`；乙炔 `CH≡CH`；丙烯 `CH3CH=CH2`；氯乙烯 `CH2=CHCl`；1,3-丁二烯 `CH2=CHCH=CH2`。
   系统已支持：键级字符不参与元素计数，守恒按元素组成校验。
2. **结构简式优先**（与旧册的分子式写法构成"写法变体"，属预期行为，不用改写）：
   乙烯写 `CH2=CH2`（不写 C2H4）；乙醇写 `CH3CH2OH`（不写 C2H5OH）；乙醚写 `CH3CH2OCH2CH3`。
   带支链的用括号：`CH3CH(CH3)CH2Cl`（1-氯-2-甲基丙烷）、`(CH3)2CHCH2CH3`。
3. **聚合度 n 约定**：
   - 系数位写 `n` / `2n`（与化学式可连写或空一格）：`nCH2=CH2`、`2nH2O`；
   - 链节式：方括号链节 + 尾缀 `n`，整体一个物质：`[CH2-CH2]n`、`[CH2-CHCl]n`、`[CO(CH2)4COOCH2CH2O]n`；
   - 链节内单键短横用 `-`：`[CH2-CH2]n`。
4. **同种物质括号嵌套/氢在括号内都支持**：`CH2OH(CHOH)4CHO`（葡萄糖）、`C6H5OH`（苯酚）、`CH3COOC2H5`（乙酸乙酯）。
5. 多价离子仍用 `^`：`Fe^3+`、`SO4^2-`；单价离子尾随写：`CH3COO-`、`HCO3-`、`OH-`、`H+`。
6. 有机物一律不标 ↑↓（教材惯例），唯一例外：醛的银镜/新制Cu(OH)2 氧化中 Ag 用 `Ag↓`、Cu2O 用 `Cu2O↓`；消去产生的乙烯气体写 `CH2=CH2↑`。

## 三、LaTeX 对照增补

- `\mathrm{CH}_2=\mathrm{CH}_2` → `CH2=CH2`（下标 LaTeX 壳剥掉，`=` 保留）
- `\equiv` → `≡`（保留三键字符，不要转成 `=`）
- `\xrightarrow[\text{加热}]{\text{催化剂}}` → 主分隔符 `=` + conditions（下标条件与上标条件都进 conditions 数组）
- `\xrightarrow{\text{Δ}}` / `\stackrel{\triangle}{=}` / `\stackrel{\Delta}{\longrightarrow}` → `=` + conditions `["加热"]`
- `\rightleftharpoons` → `⇌` + reversible:true
- 行内公式 `$...$`、`\text{...}`、`\displaystyle` 等壳剥掉
- 图片型方程式（MD 中只剩图题文字）：按图题文字+化学知识书写（见第五节置信度）
- 高分子图式 `\left[\begin{array}...\end{array}\right]_n` 或结构图片：按链节式约定改写

## 四、条件词增补（写进 conditions 数组的词）

沿用 SPEC.md 的 9 词（点燃/加热/高温/催化剂/通电/光照/常温/浓硫酸/高压），另可使用：
`醇`、`水`、`NaOH溶液`、`NaOH醇溶液`、`Ni`、`FeBr3`、`液溴`、`浓盐酸`、`煮沸`、`水浴`、`水浴加热`、`50℃`、`150℃`、`500℃`、`稀硫酸`。
（℃ 数值带符号整体一个词，如 `150℃`；不要写 "170℃" 之外的杂格式。）
教材原文映射示例："MnO2 作催化剂"→`催化剂`；"△"→`加热`；"Ni 催化"→`催化剂`+`Ni` 两词；"氢氧化钠的乙醇溶液中加热"→`NaOH醇溶液`+`加热`。

## 五、聚合图片型与低置信清单

图题型聚合反应（第五章与第三章部分），按图题文字+化学知识写成 n 约定一行式。例：
- 图题「己二酸与乙二醇缩聚生成聚己二酸乙二酯和水」：
  `nHOOC(CH2)4COOH + nHOCH2CH2OH = [CO(CH2)4COOCH2CH2O]n + (2n-1)H2O`，conditions `["催化剂"]`（若有），reactionTypes `["缩聚反应"]`
- 乙烯加聚：`nCH2=CH2 = [CH2-CH2]n`；丙烯加聚：`nCH3CH=CH2 = [CH2-CH(CH3)]n`；氯乙烯加聚：`nCH2=CHCl = [CH2-CHCl]n`

**缩聚副产物系数按教材规则书写**（人教版选三）：
- 由**一种单体**自缩聚（如 6-羟基己酸、乳酸、羟甲基苯酚）：副产物写 **`(n-1)H2O`**
- 由**两种单体**缩聚（如二元酸+二元醇、二元胺+二元酸）：副产物写 **`(2n-1)H2O`**
- 系数带括号整体书写（解析器同时接受裸写 `n-1`/`2n-1`，规范化为带括号形式）；
  加聚无副产物，不涉及本规则。

**置信度自评**（每条聚合/图题型 entry 自评 high / medium / low）：
- high：教材正文或图题明确给出反应物与产物，写法唯一；
- medium：图题文字完整但结构简式需要自己构建；
- low：图题只有示意（如"图5-6 缩聚反应示意图"）、或副产物系数需推测、或聚合物结构按教材惯例简化。
自评 low 的条目：**照常提取进 entries**，同时把
`{ "name": ..., "line": ..., "reason": "低置信原因" }` 追加写入 `organic-low-confidence.json`（数组，随分片追加，最后汇总去重）。

聚合式按「每组」（n 取 1）比较元素组成：教材 (n-1)/(2n-1) 副产物写法因链节方括号
省略端基会恰差一分子 H2O——系统识别为教材端基约定（专属提示，不作 error）；
其余不严格配平同样只给 warning 不给 error。严格式（nH2O/2nH2O）仍可解析且无端基提示，
但提取缩聚式时**一律采用教材规则的 (n-1)/(2n-1) 写法**。

## 六、reactionTypes 使用指引（六新值）

本册可用六个有机新值：`取代反应 / 加成反应 / 消去反应 / 酯化反应 / 加聚反应 / 缩聚反应`。
- 卤代烃水解（C2H5Br + NaOH → C2H5OH + NaBr）：取代反应
- 乙烯/乙炔/苯的加成（加 H2/H2O/HCl/Br2）：加成反应
- 醇/卤代烃消去（生成烯烃）：消去反应
- 酸+醇生成酯：酯化反应（**不写**"取代反应"）
- n 个单体聚合成高分子链节：加聚反应（单体含 C=C）/ 缩聚反应（并脱小分子）
- 氧化还原类（醇→醛→酸的催化氧化、醛的银镜、燃烧、葡萄糖的氧化/发酵）沿用现有值 `氧化还原反应`（可再叠加`燃烧反应`）
- 水解类（酯/糖类水解）沿用 `水解反应`
- 涉及可逆号的叠加 `可逆反应`；羧酸酸性、酚与 NaOH 等叠加 `复分解反应`
- 有机燃烧（甲烷/乙烯/乙醇燃烧若在本册出现）叠加 `燃烧反应`+`氧化还原反应`

substanceCategories 有机条目一律含 `有机物`；knowledgeModules 一律含 `有机化学`。

## 八、离子式的取舍（本册特例）

- **默认不写离子式**（系统不再自动生成）；
- **仅当教材明确给出离子方程式原文**（如"酯在 NaOH 溶液中水解"给出
  `CH3COOC2H5 + OH- = CH3COO- + C2H5OH`、皂化反应）才补 ionic version；
- 酚/羧酸酸性对比如无原文离子式，只写 chemical。

## 九、对 SPEC.md 规则的覆盖

- SPEC.md 第六节规则 4「聚合记法进 excluded」**本册不再适用**：改用第五节 n 约定提取；
  确实无法用 n 约定表达的（如蛋白质肽链、结构图片无法转写）才进 excluded。
- 淀粉/纤维素水解写 `n(C6H10O5)?` 严格按教材：`(C6H10O5)n + nH2O = nC6H12O6`（淀粉在酸催化下水解），
  系统支持方括号/圆括号链节 + n 系数。
- 糖类/油脂等旧册已有的反应：照常提取（父代理按反应物/生成物化学式集合判重决定导入策略，
  写法变体如 CH2=CH2 与 C2H4 会保留双条目，属预期）。

## 十、典型核对用例（提取完成后逐条自检）

1. 乙烯加 Br2：`CH2=CH2 + Br2 = CH2BrCH2Br`（加成反应）
2. 乙醇消去：`CH3CH2OH = CH2=CH2↑ + H2O`，conditions 按教材原文（如 `["浓硫酸","170℃"]`；℃ 数带符号整体一个词，未收录的 ℃ 值也整体保留）
3. 乙炔加 HCl：`CH≡CH + HCl = CH2=CHCl`（加成反应）
4. 酯化：`CH3COOH + CH3CH2OH ⇌ CH3COOC2H5 + H2O`（酯化反应、可逆反应，conditions 浓硫酸+加热）
5. 卤代烃 NaOH 水解：`CH3CH2Br + NaOH = CH3CH2OH + NaBr`，conditions `["NaOH溶液"]`（取代反应）
6. 卤代烃消去：`CH3CH2Br + NaOH = CH2=CH2↑ + NaBr + H2O`，conditions `["NaOH醇溶液","加热"]`
7. 苯硝化：`C6H6 + HNO3 = C6H5NO2 + H2O`，conditions `["浓硫酸","50℃"]`（取代反应）
8. 银镜：`CH3CHO + 2Ag(NH3)2OH = CH3COONH4 + 2Ag↓ + 3NH3 + H2O`，conditions `["水浴加热"]`（氧化还原反应）
9. 葡萄糖发酵：`C6H12O6 = 2CH3CH2OH + 2CO2↑`（教材如用 C2H5OH 写法则照原文）
10. 乙烯加聚：`nCH2=CH2 = [CH2-CH2]n`（加聚反应）
11. 己二酸+乙二醇缩聚：`nHOOC(CH2)4COOH + nHOCH2CH2OH = [CO(CH2)4COOCH2CH2O]n + 2nH2O`（缩聚反应）
